## Textarea

Multi-line text input field


**Source:** [`packages/appkit-ui/src/react/ui/textarea.tsx`](https://github.com/databricks/appkit/blob/main/packages/appkit-ui/src/react/ui/textarea.tsx)


### Props

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `agentId` | `string` |  | - | Stable id the agent uses to target this textarea via the `set_value` tool. Omit to auto-derive one from the placeholder/name. Only effective inside an `&lt;AgentToolsProvider&gt;`. |



### Usage

import { Textarea } from '@databricks/appkit-ui';
