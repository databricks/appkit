## Checkbox

Checkbox input for selecting multiple options


**Source:** [`packages/appkit-ui/src/react/ui/checkbox.tsx`](https://github.com/databricks/appkit/blob/main/packages/appkit-ui/src/react/ui/checkbox.tsx)


### Props

| Prop | Type | Required | Default | Description |
|------|------|----------|---------|-------------|
| `checked` | `CheckedState` |  | - | - |
| `defaultChecked` | `CheckedState` |  | - | - |
| `required` | `boolean` |  | - | - |
| `onCheckedChange` | `((checked: CheckedState) => void)` |  | - | - |
| `asChild` | `boolean` |  | - | - |
| `agentId` | `string` |  | - | Stable id the agent uses to target this checkbox via the `toggle` tool. Omit to auto-derive one from the accessible label. Only effective inside an `&lt;AgentToolsProvider&gt;`. |



### Usage

```tsx
import { Checkbox } from '@databricks/appkit-ui';
```
